🏭 Automated Industrial Metal Surface Defect Classification

MATLAB • Deep Learning Toolbox • CNN • EfficientNet-B0 • AlexNet • Transfer Learning

Built an end-to-end computer-vision pipeline for 5-class industrial metal-surface defect classification using 15,000 images across crack, hole, normal, rust, and scratch categories.

• Compared a custom Shallow CNN with EfficientNet-B0 and AlexNet transfer-learning models
• Used a 70/15/15 train-validation-test split
• Evaluated six training configurations using accuracy, precision, recall, specificity, F1-score, weighted F1, Cohen’s kappa, and confusion matrices
• Best reported configuration: EfficientNet-B0 • Adam • 100-epoch setting • 100% test accuracy on the project test split
• Documented limitations around external validity and the need for real-world validation

🔐 PySpark Multi-Class Network Traffic Classification

PySpark • Spark MLlib • Decision Tree • Random Forest • PCA • K-Means

Developed a distributed machine-learning pipeline for multi-class network-traffic classification using the CICIDS2017 dataset.

• Processed approximately 2.52 million network records
• Used 52 numerical features and 7 traffic/attack classes
• Implemented cleaning, median imputation, VectorAssembler, class weighting, and stratified splitting
• Compared a Decision Tree baseline with a Weighted Random Forest
• Tuned Random Forest configurations with 3-fold cross-validation
• Added an unsupervised branch using StandardScaler → PCA → K-Means with silhouette analysis
